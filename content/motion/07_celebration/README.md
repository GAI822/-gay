# 企画7「洗濯物をかごに入れただけ」

ハイが靴下を洗濯かごに投げ入れただけで、全力のゴールパフォーマンス（走り込み→空中で半回転→脚を開いて両腕を広げる決めポーズ）。最後にクロがかごを倒す。

- 参考に送られた試合映像は、動きを見て文章で再現するためだけに使った。映像そのものは入力に使っていない（放送局・選手本人の映像のため）。選手名もタイトルに入れない。
- `start_frame.png`: gpt_image_2_5 medium 2k（1クレジット）。
- `take.mp4`: Kling 3.0 std・音なし・7秒（10.5クレジット）、1本だけ生成。
- `hai_celebration_final.mp4`: 投稿用（5.6秒）。`edit.sh` で冒頭の静止1.4秒を切り、字幕と `../sfx.py` の合成効果音を付けた。

費用: 11.5クレジット（企画6の51クレジットの約4分の1）。

## 作り直し版（字幕なし）: `洗濯物をかごに入れただけ.mp4`（5.0秒）

依頼: ハイが奥のドアの前からかごに投げ入れ、ドアの前から助走して、カメラの手前でゴールパフォーマンス。腕はもっと力ませて斜め下に。字幕なし、字幕の文章を動画名に。

| ファイル | 内容 | クレジット |
|---|---|---:|
| `start_frame_v2.png` | ハイが奥のドア前、かごが中ほど、手前が空いた構図 | 1 |
| `take_v2.mp4` | 8秒 std 音なし。走り・跳躍は良いが、決めポーズの腕がほぼ水平 | 12 |
| `pose_frame.png` → `end_frame_pose.png` | take_v2 の決めポーズを、腕が斜め下に力む形に描き直した画像（1回目は下げすぎて床に付いたのでやり直し） | 2 |
| `take_v3.mp4` | end_frame_pose.png を最後のコマに指定。腕は狙いどおりだが、走る途中は毛色が紺色に崩れた | 12 |
| `edit_v2.sh` | take_v2 の投げ〜着地と take_v3 の決めポーズをつなぎ、投げた後の待ち時間を切り、決めポーズで1秒止めてゆっくり寄る。合成効果音つき | 0 |

作り直しの費用: 27クレジット（企画7の合計 38.5）。

## 動き移し版: `洗濯物をかごに入れただけ_動き移し版.mp4`（6.1秒・字幕なし）

依頼: シュートの後に、送られた動画の人の動き（ゴールパフォーマンス）をハイに被せる。

- 送られた動画はサッカー中継（第三者の映像）。権利のリスクを説明したうえで、本人の判断で動きの元に使った。
  中継映像の切り抜き（`motion_src/driving.mp4`）はリポジトリに入れていない。完成動画に元の映像は映っていない。
- `motion_src/driving.mp4`: 中継映像からアプリの表示を切り落とし、走り込み〜着地の2.7秒だけを切り出したもの。
- `motion_src/hai_subject.png`: 部屋の中ほどで立つハイ（1クレジット）。
- `motion_src/transfer_lite.mp4`: Genjutsu Lite 720p（`hf_mult_motion_control_flash`、8クレジット）。標準版は28クレジット。
- `edit_v3.sh`: take_v2 の投げる場面とつなぎ、1080x1920 に揃え（上下はぼかし）、最後のポーズを0.8秒止め、合成効果音を付けた。

費用: 9クレジット。

## ノーカット版: `洗濯物をかごに入れただけ_ノーカット版.mp4`（7.0秒・字幕なし）

依頼: 投げてから助走してゴールパフォーマンスまで、一連の流れをノーカットで。

- `take_onetake.mp4`: Kling 3.0 pro・音なし・8秒（14クレジット）。最初のコマ＝start_frame_v2.png（奥のドア前）、最後のコマ＝end_frame_pose.png（腕を力ませて斜め下）。
  走り込みは送られた動画の動き（腕を広げて走る→回転ジャンプ→着地）を文章で指示した。
- pro でも走る〜跳ぶ間に毛色が紺色に寄った。`../fix_blue.py`（青い画素だけ色を抜いて明るくする）で直したのが `take_onetake_colorfix.mp4`。顔の一部がやや白っぽくなる。
- `edit_onetake.sh`: 途中は切らず、投げる前の最初の1.0秒だけ削って合成効果音を付けた。

費用: 14クレジット。

## 動き移しノーカット版: `洗濯物をかごに入れただけ_動き移しノーカット版.mp4`（7.0秒・字幕なし）

依頼: 動き移し版をノーカットで。毛の色が変わらないように。

- 中継映像は走り込み〜着地の2.7秒しかなく、投げる場面がないため、通しの動きの元にはできない。
- 代わりに、ノーカット版の通しの動き（投げる→腕を広げて走る→回転ジャンプ→着地。Kling で生成した自前の動画）を
  `motion_src/driving_onetake.mp4` にし、グレーのハイの画像（start_frame_v2.png と motion_src/hai_subject.png）に移し直した。
- `motion_src/transfer_onetake.mp4`: Genjutsu Lite 720p（14クレジット）。ハイは画像から描き直されるので、毛色は全編で明るいブルーグレーのまま。
- `edit_transfer_onetake.sh`: 途中は切らず、1080x1920 に拡大して合成効果音を付けた。

費用: 14クレジット。
