# 企画8「昼寝中に氷水」: `ハイの日常_昼寝中に氷水.mp4`（7.9秒・字幕なし）

依頼: ハイがハンモックで昼寝しているところに、クロがバケツの氷水を一気に浴びせる。参考動画（いたずら動画）の人にハイとクロを被せる。
そのあと、2本目の動画の黒いズボンの人の動きをハイに被せて、クロを煽る。

- 参考動画は2本とも第三者の映像。動きの元としてだけ使い、切り抜き（`motion_src/driving_*.mp4`）はリポジトリに入れていない。完成動画に元の映像は映っていない。
- `motion_src/scene_prank.png` / `scene_taunt.png`: ハイとクロを被せる側の画像（gpt_image_2_5、各1クレジット）。
- いたずら: 画面録画なので YouTube の表示を消して2人が収まる範囲に切り出した（`driving_prank_plain.mp4`）。
  人物に重なる再生ボタンまでぼかした版（`driving_prank.mp4`）は、Genjutsu が2回とも即失敗した（返金あり）。ぼかしで姿勢が読めなくなったためとみられる。
  → `motion_src/transfer_prank.mp4`（Genjutsu Lite、8クレジット）。元動画の男性ほど派手には転げ落ちない。
- 煽り: 黒いズボンの人が前で踊る約1.2秒だけを切り出し、`../isolate_subject.py` で他の2人を消した（`driving_dance.mp4`）。
  → `motion_src/transfer_taunt.mp4`（Genjutsu Lite、8クレジット）。
- `edit.sh`: いたずらの場面を正方形に切り詰め、2本をつないで 1080x1920 に揃え（上下はぼかし）、合成効果音（水しぶき・バケツ・着地・足音・リズム）を付けた。
