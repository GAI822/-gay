# ハイのストーリー動画 企画（2026-11-26）

方針: ハイの動きは**全部、実在の人の動きを移す**（動き移し `hf_mult_motion_control_flash`）。
猫どうしのからみや小物の動きだけ Kling（`kling3_0`）で補う。セリフと字幕は入れず、動き・表情・効果音・間で話を見せる。

## 共通の作り方

| 項目 | 内容 |
|---|---|
| 尺 | **45〜60秒**（ショートの上限は3分だが、話を追える最短の長さにする。1カットは3〜5秒、全12〜15カット） |
| 1カットの作り方 | ①その場面のハイの立ち姿の画像（gpt_image_2_5、1クレジット）→ ②見本の人の動きを移す（約7〜10クレジット） |
| 見本の動き | `content/autopilot/drivers/drivers.json` の13本（Mixkit、商用・加工可）＋足りない動きを Mixkit で追加 |
| つなぎ | カットはパッと切り替え。効果音はこれまでの合成音。冒頭1秒に一番の見せ場を先出し |
| 1本の費用 | 約100〜140クレジット（12〜15カット）。今月の残り約390なら2本まで |
| 公開 | 3部に分けて「Part 1/2/3」で出す案もある（1本の費用は同じで、投稿数を3倍にできる） |

## 企画B「ハイのダイエット3日間」（約50秒・12カット）

体重計で現実を知ったハイが、3日間トレーニングして最後の計量に挑む。
1日目・2日目・3日目で分けて、**3本のシリーズ**にもできる。

| 日 | 場面 | 移す動き |
|---|---|---|
| 1日目 | 体重計に乗る → 頭を抱える → 決意の力こぶ | 4508 → 33616 |
| 2日目 | 回し蹴りの練習 → 筋トレ → 夜、冷蔵庫の前でおやつを見つめる（Kling） | 49634 → 追加: man doing push ups |
| 3日目 | ミルクにおやつを渡して我慢 → 計量 → 喜びのダンス | 49706（お辞儀して渡す）→ 36152 |
| オチ | 体重計の数字は変わらず、後ろでマロ（子猫）がずっと乗っていた | 肩をすくめる 45503 |

費用: **約105クレジット**。

## 進め方

1. 企画を1つ選ぶ（おすすめはA）。
2. 新キャラ（ボス／マロ）の設定画像を作る（各2〜3クレジット）。
3. 足りない見本の動きを Mixkit で探して足す（無料）。
4. カットごとに作って確認しながらつなぐ。1本あたり作業は数時間。
