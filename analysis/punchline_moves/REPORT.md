# オチに使える「人の面白い動き・ポーズ」の分析（2026-11-23）

## 何を集めたか

| SNS | 取れた本数 | 方法 |
|---|---:|---|
| **YouTube** | **7,585本** | 動きの名前で43種類×2前後の検索語を作って検索し、90秒以下の動画を2,821本集めた。前回集めた再生100万回以上の4,764本（`../human_motion_1000`）と合わせた |
| TikTok | 0本（直接） | タグ・ユーザーのページを開いても、動画の一覧が中に入っていない（ログインと署名付きの通信が必要）。 |
| Instagram | 0本（直接） | タグのページはログインが必要。 |
| X | 0本（直接） | 検索はログイン画面に飛ばされる。 |
| Threads | 0本（直接） | 検索はログインが必要。 |

- ブロックを偽装ですり抜けることはしていない。
- **代わりに使ったもの:**
  - YouTube にある他SNSからの転載: タイトルに tiktok / reels / instagram / #fyp などが入る動画215本。
  - 2026年の流行をまとめた記事: TikTok のダンス、Instagram リールのミーム、X の反応ミーム。
- **このデータでは「TikTok・Instagram・X・Threads で各1,000本以上」は満たせていない。** 満たすには、持ち主のアカウントで見た流行りの動画を送ってもらうのが確実。

## 分け方とその限界

- **型の分け方:** タイトルに動きの名前（moonwalk、dab、flex、siu、celebration、freeze…）が入っているかで分けた（`moves.py`）。
- **限界:**
  - 映像の中身は見ていない（個別ページはボット判定で開けない）。
  - タイトルに動きの名前が出ない動画は数えていない。
  - 違う意味の語も拾っている。slow mo は理科の実験、bow は弓、moonwalk は月面歩行の解説も含む。
  - 本数は小さいので、順位は目安。
- **数字の扱い:** 検索で取れた動画には再生数が欠けたものがある。そのため中央値ではなく「再生100万回以上の本数」で並べた。

### 他SNSの流行（記事から。数字の裏付けは弱い）
- **TikTok:** 2人組のダンスが増えている。2016年ごろのダンスを今の曲でやり直すものも多い。毎月、新しい「〜チャレンジ」が出る。
- **Instagram リール:** 体で文字を作るポーズ（ペットが参加する型が多い）、天井に張りついた口パク、真顔で妙に細かい返しをする型。
- **X など:** 有名ミームのポーズを自分で撮り直す型、反応ミーム（猫の無表情や「読み込み中」の顔）。

## 読み取れたこと

1. **再生される「オチ」は、誰でも知っている動きやポーズ。** 決めポーズ・ゴールパフォーマンス・ムーンウォーク・力こぶなど、1秒で「あれだ」と分かるものが上位。
2. **動きは最後に、静止つきで見せる。** 上位の多くは決めの形でピタッと止まる。止まった瞬間が、サムネや冒頭の1枚になる。
3. **同じ動きを状況だけ変えて量産している。** 決めポーズのミームは「〜の声で」「〜の世界で」と、状況を変えたものが何本も100万回を超えている。
4. **曲や作品と結びついた動きは、名前を出すと権利の問題になる。** 形だけ使い、名前は書かない。

## ハイの動画に入れたもの

- `content/autopilot/PUNCHLINES.md`: 猫ができる形に直した20の動きと、Kling 用の英文。
- `content/autopilot/ideas.md`: 残りの企画すべてに「オチの動き」を付けた。
- `content/autopilot/finish.sh`: `TEASER="秒:0.9"` で、オチの決めの瞬間を冒頭0.9秒に先出しする。そのあと巻き戻し音と白い一瞬のフラッシュを挟んで本編へ。
- `content/autopilot/RUNBOOK.md`: 上の3つを毎日の手順に入れた。
