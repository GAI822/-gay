# 再生100万回以上の猫ショート 1,169本の分析と企画案（2026-11-05）

## 1. 何を集めたか（と、集められなかったもの）

- **対象:** YouTube のショート。タイトルに猫を含み、再生100万回以上のもの。
- **集め方:**
  1. 「人の動きを猫に被せた系」に近い検索語を105個用意した（日本語・英語・中国語・韓国語ほか）。例: AI cat dance、cat kung fu、猫 ダンス AI。
  2. 検索で約7,000本の動画と4,861チャンネルを見つけた。
  3. 各チャンネルのショート一覧から再生数を取った。100万回超えが多いチャンネルは、さらに400本まで掘り下げた。
- **結果:** 条件に合う動画は **1,706本・166チャンネル**。1チャンネルが結果を独占しないよう各チャンネル上位30本までに絞り、**1,169本（総再生140億回、中央値310万回）** を分析した。
- **使った情報:** タイトル、再生数、登録者数、サムネ（＝動画内の1フレーム）。サムネからは、猫の顔の検出・文字の有無・明るさを見た。

**取れなかったもの（正直に）**
- **他人の動画の視聴維持率・スワイプ率:** 投稿者本人しか見られない。2章の「スワイプされない理由」は、作りの共通点からの**推定**。あなた自身の Studio の数字（前回）と突き合わせて裏付けている。
- **動画の長さ:** ショート一覧には長さが出ず、個別ページはボット判定で開けなかった。
- **Instagram・TikTok:** ログインが必要で取得できない。参考の4本はInstagramのリールなので、ここが一番大きな穴。
- **「人の動きを猫に被せた」動画そのもの:** YouTube の100万回超えには少なかった。ダンス・格闘・人間っぽい動きの動画は1,169本中88本で、その多くはアニメかミーム合成だった。この形式は今のところ **Instagram・TikTok が主戦場** で、YouTube ではまだ空いている可能性がある。

比較できたのは「100万回を超えた動画どうし」だけで、伸びなかった動画は含んでいない。以下は相関で、因果の証明ではない。

## 2. 分かったこと

### 2-1. ジャンル別

| ジャンル | 本数 | 再生数中央値 | 登録者数に対する再生倍率 |
|---|---:|---:|---:|
| 実写の飼い猫（料理ASMR・日常） | 401 | 280万 | 5.3倍 |
| 実写＋人の声・字幕でキャラ化（POV字幕・アフレコ） | 117 | 370万 | 4.6倍 |
| **AI生成の猫** | 41 | **510万** | **27倍** |
| ミーム猫の合成・編集（バナナ猫などを場面に合成） | 253 | 310万 | 7.0倍 |
| アニメ・子ども向け・ゲーム | 357 | 350万 | 1.7倍 |

- **AI生成の猫は本数こそ少ないが、登録者数の27倍再生されている。** 登録者ではなく、おすすめ欄で知らない人に届いている。見たことのない映像は、YouTubeが外に広げやすい。
- **「猫に人間の中身を入れる」系が全体の3割強。** 人の声や字幕を乗せる（POVINME、私はDくん）、ミーム猫を人間の場面に合成する（The Cat Adventures、XoSen7）。猫の見た目に人間の気持ちや動きを投影する作りが、ジャンルをまたいで強い。

### 2-2. 当たりは同じチャンネルに固まる

- 100万回超えのうち **74%は、100万回超えを10本以上持つ41チャンネルの動画**。100万回超えが1本だけのチャンネルは62。
- 100万回超えの動画で、登録者10万人未満のチャンネルのものは8%しかない。
- → 一発バズより、**同じ型を出し続けたチャンネルが当たりを量産している**。型が決まると、似た動画が続けておすすめされる。

### 2-3. タイトル

- 中身のキーワード別では、**料理（中央値720万）、物語（390万）、音楽（400万）**が高い。**ダンスは235万**と、ジャンルの中では低めだった。
  ダンスだけでは差別化しにくく、「何をしているか」「どうなるか」がある動画の方が上。
- 「POV」は中央値1,500万と飛び抜けて高いが、ほぼ POVINME 1チャンネルの数字なので参考程度。
- 英語など欧文タイトルが84%（中央値360万）、日本語は14%（240万）。**言葉に頼らない作り＋英語タイトル**で世界に届けている動画が多い。
- ハッシュタグあり55%（360万 vs なし265万）。#cat #shorts などジャンルを示すタグは付けた方がよい。

### 2-4. 画面（動画内フレーム）

- **画面に文字があるのは51%。** 「人の声・字幕でキャラ化」に限ると74%で、上部に1行の状況説明（"POV: 夜中2時に赤ちゃんを見つけた"）を出すのが定番。
- **猫の顔のアップは6%しかない。** 状況が分かる引きの画（猫の全身＋周りの物）が基本。
- ミーム合成系は正面顔が52%と多い。誰でも知っている「あの猫の顔」で、一瞬で何の動画か伝えている。

## 3. スワイプされず、長く見られる理由（推定）

前回の Studio の数字では、あなたの動画は「視聴を継続」の率が再生数の順位とそのまま一致していた。最初の1〜2秒でスワイプされないことが最大の分かれ目。100万回超えの動画は、この1〜2秒を次のどれかで突破している。

1. **0.5秒で状況が分かる。** 上部の1行字幕（POV〜）か、一目で分かる異常な画（猫が料理している、猫が人間の場面にいる）。
2. **結末が気になる。** 料理の完成、救出の結果、物語の続き。「最後まで見ないと分からない」構造が、平均視聴時間を伸ばす。料理系の中央値720万はこれ。
3. **知っている顔・知っている音。** ミーム猫の顔や流行の音（OIIA、Soda Pop など）は、説明なしで脳が理解する。
4. **猫に人間の中身。** 人の声や人の動きが入ると、「猫なのに人間」というズレが、繰り返し見る動機になる。参考リールの、人の動きを被せた猫もこれ。
5. **短く、ループする。** 1本1出来事で、最後が最初につながる。あなたの Door vs Me（15秒）が平均視聴132%だったのと同じ仕組み。

## 4. 企画案（ハイを使う）

ハイ＝人間味の無い、無表情のブルーグレーの猫（`character/hai/`）。中身（動き・声）だけを人間にする。

### 共通ルール
- 8〜15秒、1本1出来事。最初のフレームから動いている。最後は最初の構図に戻してループさせる。
- 上部に英語1行＋日本語1行の状況字幕（例: "POV: you asked your cat to do the dishes"）。
- 音は YouTube のショート用ライブラリから選ぶ。流行の音は使用許可のあるものだけ。
- AI生成であることを開示する（YouTube の「改変・合成コンテンツ」ラベル）。
- 毎回 Studio の「視聴を継続」を記録し、**50%を超えた型だけ量産する**（今のチャンネル内最高は51.0%）。

### 企画A「POV: 猫に〇〇を任せた」（本命）
- **中身:** 人が家事・仕事・料理をキビキビ演じ、ハイに被せる。ハイは無表情のまま、動きだけ有能すぎる。
- **根拠:** 字幕で状況説明（2-4）＋猫に人間の中身（3-4）＋料理・作業の結末（2-3）。
- **例:**
  - 皿洗い
  - 洗濯物たたみ
  - 確定申告
  - 引っ越しの荷造り
  - リモート会議で発言する
  - 朝のルーティン

### 企画B「完成まで見て」（料理・工作の過程）
- **中身:** ハイが材料から完成まで、20秒以内で作り切る。最後は無表情で一口食べて、最初のカットに戻る。
- **根拠:** 料理は中央値720万で、キーワード別の最高（POVを除く）。結末が気になるので最後まで見られる。

### 企画C「流行りの動き × 無表情の猫」
- **中身:** 流行りのダンスやカンフーの型を、人が全身で演じてハイに被せる。参考リール1・2の型。
- **注意:** ダンス単体の中央値は235万と低め。流行が出て48時間以内に出すこと、タイトルに曲名・ミーム名を入れることが条件。拡散用の補助企画として扱う。

### 企画D「ハイの物語」シリーズ（3〜5話）
- **中身:** 毎話15秒で、続きもの。例: 迷子のハイが家に帰るまで、ハイの初バイト。ハイは毎回同じ見た目。
- **根拠:** 物語の中央値390万。当たりがシリーズのチャンネルに固まる（2-2）。

### 企画E「人間 vs ハイ」
- **中身:** 同じ動きを、左に演じた人、右にハイで並べる。作り方そのものをネタにする。
- **根拠:** 「Tom & Jerry in Real Life」（4,300万回）のように、本物と再現を並べる形は100万回超えに実例がある。

### 進め方
1. 最初の2週間は、A・B・Cを各3本、計9本出す。
2. 「視聴を継続」が一番高い型を、次の2週間は毎日出す。
3. 50%に届かなければ、冒頭0.5秒の画と字幕だけを差し替えて再挑戦する。中身は変えない。

## 再現方法

```
python3 discover.py && python3 discover.py --extra   # 検索で候補を集める
python3 channels.py                                  # チャンネルを特定
python3 crawl.py 2 150 && python3 crawl.py 1 60      # ショート一覧から再生数
python3 build.py && python3 deep.py && python3 build.py
python3 analyze.py   # OpenCV 4 系が必要（猫の顔検出）。結果は report_stats.txt
```
