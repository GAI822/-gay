# ハイ（HAI）— 人間味の無い、ただの猫

人の動きを被せる動画の「器」になる猫。猫自身には性格も服も表情も付けない。
人の演技が乗ったときのギャップ（無表情の普通の猫が、急にキレのある人間の動きをする）が笑いになる。

| ファイル | 用途 |
|---|---|
| `00_sheet.jpg` | 4枚を並べた確認用シート |
| `01_floor_full.png` | 床の全身（ダンス・カンフーの開始フレーム） |
| `02_floor_front.png` | 床の正面（同上、カメラが低めのとき） |
| `03_sofa.png` | ソファ（日常ネタ・座った演技の開始フレーム） |
| `04_face.png` | 顔の寄り（目と毛並みの確認用。口パクには寄りすぎ） |

## 見た目の固定ルール

| 部位 | 固定値 |
|---|---|
| 毛 | 柄なしのブルーグレー単色、短毛で密 |
| 目 | 黄色〜黄緑、縦長の瞳孔 |
| 鼻 | くすんだピンクグレー |
| 体型 | 細身で脚が長め、耳は大きめで立っている |
| しっぽ | 1本、体と同じグレー（先だけ少し濃くてもよい） |
| 表情 | 無表情。笑わせない、目を細めさせない |
| 服・首輪 | **何も付けない** |
| 撮り方 | スマホ手持ち、家の床・ソファ、天井照明、少しノイズ |

単色の猫にしたのは、柄が少ないほど動画にしたときに模様が崩れにくく、毎回同じ猫に見えやすいため。
参考リールの猫（シルバータビー、黒猫、白黒）とも被らない。

## 作り方と限界

- この4枚は Higgsfield の残高不足のため、この環境の CPU で SDXL-Turbo を動かして作った（`gen_local.py`、1枚2〜8分）。
- 11枚作って、毎回同じ猫に見えることは確認できた。
- **できなかったこと:** 「後ろ足で立つ」「胸から上だけ」の構図はこのモデルでは指示が効かず、全部お座りになった。
  モーション転写では動きは人の動画から来るので、お座りの開始フレームでも使える。立った絵が必要なら Higgsfield（`gpt_image_2_5`）で `01_floor_full.png` を参照にして作り直す。
- 解像度は 576×1024。Higgsfield の `upscale_image` で上げてから動画化するとよい。
